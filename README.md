# dogfight19

Exercice de cours Java : jeu de combat aérien, avec une première séparation entre la boucle de jeu
et l'affichage.

## Contenu

- `src/jpu2016/dogfight/` : contrôleur, modèle (avion, missile, nuages, zone de jeu)
- `gameframe/` : fenêtre et panneau de jeu, interfaces d'événements et de rendu

## Stack

Java, Swing.

## Lancer le projet

Importer le projet dans Eclipse et exécuter le point d'entrée du dossier `gameframe`.

## Contexte

Exercice d'école (2019), avant la version plus complète `dogfight`.
